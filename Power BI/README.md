Power BI Dashboard

This folder contains the Power BI dashboard developed for the IKEA Gifting Customer Analytics & RFM Segmentation project.

Dashboard Contents

- Business overview
- Customer analysis
- Revenue analysis
- RFM customer segmentation
- Geographic customer analysis

File

- "ikea_gifting_customer_analytics.pbix": Power BI dashboard file.

The dashboard is designed to communicate customer value, purchasing behaviour, and churn risk based on the project's business requirements.
